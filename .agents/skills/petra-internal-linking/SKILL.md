Read the [link graph](../../../data/internal-links.json) and the latest [crawl](../../../data/crawl-health.json). Confirm both exact routes serve indexable canonical HTML and check the body where a reader would need the next step.

1. Review links from a buyer guide or process page to private label, contract/OEM or stainless steel production.
2. Use a short anchor a brand buyer recognizes. Include the exact source, destination and placement.
3. Prefer an existing contextual link when it already helps the reader.

Done when a human can review each placement and both URLs pass the crawl gate. Adapted from [Illyism's internal-linking method](https://github.com/Illyism/seo-skills).
